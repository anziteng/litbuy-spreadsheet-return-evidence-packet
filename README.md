# LitBuy Spreadsheet Return Evidence Packet

This repository publishes an independent static resource for a **LitBuy Spreadsheet return-evidence packet review**. It includes a four-page evidence workflow and a reusable CSV worksheet.

## User output

The workflow produces an evidence packet index separating the request, identity, observed condition, dated media, communication, and gaps. It does not fetch private files or claim current inventory, price, quality, shipping, or policy outcomes.

## Files

- `index.html` — task overview, evidence method, worked example, and stop rule
- `faq.html` — scope, evidence, exception, and handoff questions
- `usage-guide.html` — four-step workflow and review worksheet instructions
- `alternatives.html` — evidence-based decision paths
- `review-template.csv` — portable fields for recording one review
- `robots.txt` and `sitemap.xml` — public crawl files for the generated site

## Boundary

Always reopen the linked live resource when a decision depends on changing platform details. Keep visible evidence, reviewer interpretation, and unresolved questions separate.
